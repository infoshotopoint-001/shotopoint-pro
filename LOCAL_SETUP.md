# Local setup (HTML/JavaScript + Node.js)

Read `README_HTML_JS.md` for the current setup. The website pages are static HTML/CSS/JavaScript and the Node.js API provides database-backed operations. Configure MySQL and `.env`, then run `npm install` and `npm start`. Static pages can load if MySQL is offline, but database-backed functions will not work until it is configured. Open `http://127.0.0.1:5000/`.
